# Badri Saithanmai - AI/ML Engineer & Data Analyst Portfolio

A modern, responsive, and high-performance personal portfolio website built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## 🚀 Features

- ⚡ **Next.js 14 App Router:** High performance, SEO optimized with Server/Client components.
- 🎨 **Glassmorphism Aesthetic:** Dark mode background, neon cyan/violet ambient glows, smooth backdrop blur cards.
- 📱 **Fully Responsive:** Customized mobile menu drawer, adaptive layout grids across screen sizes.
- 🛠️ **Filterable Projects Grid:** Category tabs for Machine Learning, Voice & Web AI, and Data Analytics + detail modal view.
- 📈 **Interactive Timeline:** Vertical career timeline detailing internships at SAL Biosciences & Edunet Foundation + B.Tech AIML degree.
- 📊 **Categorized Skills Matrix:** Visual tech stack badges for Data Science, Dashboards, Databases, and Soft Skills.
- ✉️ **Contact Form:** Interactive contact form interface + direct email/phone and social links.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (TypeScript)
- **Styling:** Tailwind CSS
- **Icons:** `lucide-react`
- **Animations:** `framer-motion`
- **Fonts:** Inter & Outfit (via `next/font`)

## 💻 Getting Started

```bash
# Clone repository
git clone https://github.com/BSaiThanmai/portfolio.git

# Navigate into directory
cd portfolio

# Install dependencies
npm install

# Run dev server
npm run dev
```

Open https://sai-thanmai-portfolio.vercel.app/ with your browser to see the result.

## 📦 Deployment to Vercel

1. Push your code to GitHub.
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel automatically detects Next.js 14 App Router and deploys with zero configuration.
